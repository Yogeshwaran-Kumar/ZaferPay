🔒 Security Design Philosophy

Why Hash + Encrypt Pattern?

Field Type Hash Encrypted Why?
Mobile Number mobile_hash mobile_encrypted Hash for search (login), Encrypt for display (profile)
Email email_hash email_encrypted Same pattern as mobile
Device ID device_id_hash device_id_encrypted Hash for binding check, Encrypt for audit
IP Address ip_hash ip_encrypted Hash for geo-velocity, Encrypt for investigation

Why Plain + Encrypted Balance?

Problem: Encryption prevents SUM/AVG queries.

Solution: Store both:

  • balance - Plain float for fast calculations
  • encrypted_balance - AES-256 for audit compliance

Both are updated atomically via update_balance() method.
