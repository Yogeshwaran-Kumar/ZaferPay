Run Automated Setup (Recommended)

One-click backend setup

This script creates a virtual environment and installs all Python dependencies:

.\setup_app.ps1 Run in PowerShell from project root
⚠️

If PowerShell blocks the script: Run this first:
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

What the script does:

  1. Checks if Python is installed
  2. Creates backend/venv/ virtual environment
  3. Installs all packages from requirements.txt
  4. Checks if .env file exists

✅ Expected output: "[+] Backend setup complete!"

Start the Backend Server

Choose local or remote

Option A: Local Network (Same WiFi)

Use this when your phone is on the same WiFi as your computer.

.\start_backend.bat Double-click or run from project root

✅ Expected output:

INFO: Uvicorn running on http://0.0.0.0:8000
# Find your computer's IP address: PS> ipconfig ... Wireless LAN adapter Wi-Fi: IPv4 Address. . . . . . . . . . . : 192.168.1.5 ... # Your backend URL will be: http://192.168.1.5:8000

Option B: Remote Access (Internet/Mobile Data)

Use this when you want to access the backend from anywhere (requires Ngrok).

.\start_remote.bat Starts backend + Ngrok tunnel

✅ Ngrok output:

Forwarding https://abc123.ngrok-free.app -> http://localhost:8000

Option C: Manual Command (Without Batch Files)

# Activate venv and start server PS ...\Safe Pay> cd backend PS ...\backend> .\venv\Scripts\activate (venv) PS> uvicorn main:app --host 0.0.0.0 --port 8000 --reload

Run the Mobile App

Launch on device/emulator

Option A: On Physical Android Device

  1. Enable Developer Options on your phone (Settings → About → Tap "Build Number" 7 times)
  2. Enable USB Debugging in Developer Options
  3. Connect phone via USB cable
  4. Accept "Allow USB Debugging" prompt on phone
# Check connected devices PS ...\mobile_app> flutter devices 2 connected devices: SM G991B (mobile) • R5CR******* • android-arm64 • Android 13 Chrome (web) • chrome • web-javascript # Run on phone PS ...\mobile_app> flutter run

Option B: On Android Emulator

  1. Open Android Studio → AVD Manager
  2. Create or start an emulator
  3. Wait for emulator to fully boot
PS ...\mobile_app> flutter run

✅ The app will build and install. First build takes 2-5 minutes.

Configure Mobile App to Connect to Backend

Set the server URL

  1. Open the SafePay app on your phone/emulator
  2. Tap the ⚙️ Settings icon (top-right or in menu)
  3. Find "Backend URL" or "Server URL" field
  4. Enter your backend URL:
    • Local: http://192.168.1.5:8000 (your IP)
    • Remote: https://abc123.ngrok-free.app (Ngrok URL)
  5. Tap Save
⚠️

For Local: Phone and computer MUST be on the same WiFi network.
For Emulator: Use http://10.0.2.2:8000 (special Android emulator IP)

Troubleshooting Common Issues

If something goes wrong

❌ "Connection refused" or "Cannot connect to server"

  • Make sure backend is running (terminal shows Uvicorn running)
  • Check firewall isn't blocking port 8000
  • For emulator, use 10.0.2.2 instead of localhost
  • For physical device, ensure same WiFi network

❌ "401 Unauthorized" errors

  • Token expired - log out and log back in
  • Device binding issue - try clearing app data
  • Check that .env file has correct SECRET_KEY

❌ Flutter build fails

  • Run flutter clean then flutter pub get
  • Run flutter doctor and fix any issues
  • Ensure Android SDK and licenses are accepted

❌ Python "Module not found" errors

  • Make sure virtual environment is activated (see (venv) in prompt)
  • Run pip install -r requirements.txt again

❌ Database errors

  • Current setup uses PostgreSQL on Neon Cloud
  • Check DATABASE_URL in .env is correct
  • Neon free tier may pause after inactivity - refresh the page
